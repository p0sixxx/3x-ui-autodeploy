# 3x-ui-autodeploy

Один скрипт поднимает небольшой VPN-сервис на чистом VPS: панель [3x-ui](https://github.com/MHSanaei/3x-ui), протоколы **VLESS + Reality** и **Hysteria2** на порту 443, подписки, лимиты трафика и сроки для каждого пользователя. Пользователями управляешь консольной утилитой `vpn`. Домен не нужен.

- ОС: Ubuntu 24.04, чистый сервер, root
- Ресурсы: от 1 vCPU / 1–2 ГБ RAM
- Проверено с 3x-ui **v3.9.0** (Xray 26.9.30)

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/p0sixxx/3x-ui-autodeploy/main/vpn-setup.sh)
```

---

## 1. Что получится

- **VLESS + Reality + Vision (TCP/443)** — основной протокол. Для DPI выглядит как HTTPS к крупному сайту.
- **Hysteria2 (UDP/443)** — запасной протокол, быстрее на плохих каналах. Не работает, если провайдер режет UDP.

У каждого пользователя одна ссылка-подписка, в которой есть оба протокола. Клиент обновляет её раз в 6 часов и показывает остаток трафика и дату окончания. Когда трафик кончается или выходит срок, панель сама отключает пользователя.

| Порт | Для чего |
| --- | --- |
| 443/tcp, 443/udp | подключения клиентов |
| случайный 20000–60000/tcp | веб-панель (секретный путь) |
| случайный 20000–60000/tcp | раздача подписок |
| 80/tcp | выпуск и продление сертификата Let's Encrypt |
| SSH-порт | доступ к серверу |

## 2. Подготовка

1. **Фаервол в кабинете хостера.** Откройте 22/tcp (или свой SSH-порт), 80/tcp, 443/tcp, **443/udp** и 20000–60000/tcp. Если не хотите открывать диапазон, задайте порты сами (см. параметры ниже).
2. **Порты 80 и 443 должны быть свободны.** Проверка: `ss -ltnup | grep -E ':(80|443) '` должна ничего не вывести.
3. **Вход по SSH-ключу** (желательно): `ssh-copy-id root@IP`.

## 3. Установка

```bash
ssh root@IP
bash <(curl -fsSL https://raw.githubusercontent.com/p0sixxx/3x-ui-autodeploy/main/vpn-setup.sh)
```

Если SSH-соединение может оборваться, запускайте внутри `tmux`.

Необязательные параметры указываются перед командой, например `PANEL_PORT=31337 SUB_PORT=31338 bash <(curl ...)`:

| Параметр | Что делает |
| --- | --- |
| `PANEL_PORT`, `SUB_PORT` | свои порты панели и подписок вместо случайных |
| `REALITY_TARGET=www.site.com:443` | свой сайт для маскировки Reality вместо автоподбора |
| `DOMAIN=vpn.example.com` | сертификат на домен вместо IP (A-запись уже должна указывать на сервер) |
| `TG_BOT_TOKEN=…` + `TG_ADMIN_ID=…` | Telegram-бот 3x-ui: уведомления и бэкапы |
| `ACME_EMAIL=you@mail` | e-mail для Let's Encrypt |
| `NO_FIREWALL=1` | не настраивать ufw |

Что делает скрипт:

1. Проверяет ОС, что 3x-ui ещё не установлен и что порты 80 и 443 свободны.
2. Ставит пакеты, создаёт swap на 1 ГБ, включает BBR и увеличивает UDP-буферы.
3. Генерирует случайные порты, путь к панели, логин и пароль.
4. Ставит 3x-ui v3.9.0 и получает сертификат Let's Encrypt на IP. Сертификат действует 6 дней и продлевается сам, поэтому порт 80 должен оставаться открытым.
5. С сервера проверяет сайты-кандидаты и выбирает маскировку для Reality.
6. Создаёт inbound'ы VLESS+Reality и Hysteria2 и настраивает подписки по HTTPS.
7. Ставит утилиту `vpn`, включает ufw и создаёт пользователя `me` без лимитов.

В конце скрипт выводит адрес панели, логин, пароль, вашу подписку и QR-код. Если в строке «Сертификат» написано `selfsigned`, значит у хостера закрыт порт 80 (что делать — в разделе 7).

## 4. Подключение

| Устройство | Клиенты |
| --- | --- |
| Android | Happ, v2RayTun, Hiddify, INCY |
| iPhone / iPad | Happ, v2RayTun, Hiddify |
| Windows | v2rayN, Hiddify |
| macOS | Hiddify, Happ |

Выполните `vpn link me`, затем в клиенте нажмите «+» и выберите «Импорт из буфера» или «Сканировать QR». В списке появятся два сервера, VLESS и Hysteria2. Проверьте оба, лучше с разных сетей: мобильного интернета и домашнего провайдера. Если не работает только Hysteria2, значит провайдер режет UDP, пользуйтесь VLESS.

## 5. Управление пользователями

```
vpn add vasya 100 30 "оплатил 11.10"  # 100 ГБ на 30 дней, выводит ссылку и QR
vpn list                              # трафик, лимиты, сроки
vpn link vasya                        # показать ссылку ещё раз
vpn renew vasya 30                    # +30 дней и обнулить трафик
vpn renew vasya 0 150                 # срок тот же, новый лимит 150 ГБ
vpn reset vasya                       # только обнулить трафик
vpn off vasya / vpn on vasya          # отключить / включить
vpn del vasya                         # удалить (ссылка перестанет работать)
vpn panel                             # адрес, логин и пароль панели
```

- `0` ГБ означает без лимита, `0` дней — бессрочно.
- Имя: латиница, цифры, `. _ - @`.
- `renew` продлевает от текущей даты окончания, если она ещё не наступила, иначе от сегодняшнего дня.
- Если пользователь не продлил подписку, он отключится сам в день окончания.

## 6. Панель 3x-ui

Адрес и пароль показывает `vpn panel`. Без секретного пути из адреса панель отвечает 404.

Что можно менять:
- маскировку Reality: *Inbounds → VLESS → Edit → Reality*, поля Target и SNI;
- Telegram-бота;
- `limitIp` у пользователя (сколько одновременных IP ему разрешено).

Что лучше не трогать: порт 443 и протоколы inbound'ов, сертификаты в Hysteria2. **Не перевыпускайте API-токен `vpn-cli`**: на нём работает утилита `vpn`.

## 7. Если что-то не работает

| Симптом | Что делать |
| --- | --- |
| «Заняты порты» | `ss -ltnup \| grep -E ':(80\|443) '`: найти, что занимает порт, убрать и запустить скрипт заново |
| `Сертификат: selfsigned` или скрипт упал на середине | открыть 80/tcp у хостера и переустановить (ниже), пока нет пользователей |
| Не работает ничего | `systemctl status x-ui`, `ss -ltnup \| grep 443`, `ufw status`, фаервол у хостера |
| Не работает только Hysteria2 | провайдер режет UDP или у хостера закрыт 443/udp |
| VLESS не работает из РФ, а из-за границы работает | сменить Target/SNI в панели; лучший вариант — сайт из той же сети хостера ([RealiTLScanner](https://github.com/XTLS/RealiTLScanner)). Если не помогло, IP заблокирован |
| `vpn`: «токен недействителен» | починка токена (ниже) |
| Пользователь пишет, что VPN пропал | `vpn list`: кончился трафик или срок, тогда `vpn renew` |
| Пропал SSH после установки | зайти через VNC-консоль хостера и выполнить `ufw allow <порт>/tcp` |

Починка токена:

```bash
T=$(/usr/local/x-ui/x-ui setting -getApiToken -tokenName vpn-cli | grep -Eo 'apiToken: .+' | awk '{print $2}')
sed -i "s|^TOKEN=.*|TOKEN='$T'|" /etc/vpn/vpn.env && vpn list
```

Переустановка с нуля (удаляет всех пользователей):

```bash
x-ui uninstall          # ответить y
rm -rf /etc/x-ui /etc/vpn /usr/local/bin/vpn /root/cert
bash <(curl -fsSL https://raw.githubusercontent.com/p0sixxx/3x-ui-autodeploy/main/vpn-setup.sh)
```

## 8. Обслуживание

- **Бэкап** раз в неделю, архив потом скачать к себе:
  ```bash
  tar czf /root/vpn-backup-$(date +%F).tgz /etc/x-ui /etc/vpn /root/cert /root/.acme.sh /usr/local/bin/vpn
  ```
- **Обновления системы** раз в месяц: `apt update && apt upgrade -y`, после обновления ядра — `reboot`.
- **`x-ui update` без необходимости не запускайте.** В новой версии 3x-ui может измениться API, на котором работает `vpn`. Ядро Xray безопаснее обновлять из Dashboard панели.
- **Сертификат** продлевается сам, если открыт порт 80. Проверить: `~/.acme.sh/acme.sh --list`.

| Команда | Зачем |
| --- | --- |
| `systemctl status x-ui` | работают ли панель и Xray |
| `journalctl -u x-ui -n 100` | последние логи |
| `x-ui` | меню 3x-ui |
| `ufw status` | открытые порты |

## 9. Безопасность

- После того как вход по ключу проверен, отключите вход по паролю: `PasswordAuthentication no` в `/etc/ssh/sshd_config`, затем `systemctl restart ssh`.
- Ссылка-подписка даёт доступ к VPN. Если она утекла, выполните `vpn del` и `vpn add` — пользователь получит новую ссылку.
- Если IP сервера заблокируют, проще всего поднять новый VPS этим же скриптом и раздать пользователям новые ссылки.
